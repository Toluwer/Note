# Lucide icon integration

Note uses a pinned subset of the official Lucide icon artwork through the Roblox-compatible sprite atlases published by `latte-soft/lucide-roblox` 0.1.3.

- Lucide artwork version: **0.363.0**
- Atlas cell size used by Note: **48 × 48**
- Rendering: `ImageLabel.Image`, `ImageRectOffset`, and `ImageRectSize`
- Recoloring: `ImageColor3`
- No guessed or fabricated Roblox asset IDs are used.

`manifest.json` contains the exact image IDs and sprite offsets used by the runtime registry. The subset is limited to icons used by Note's built-in controls and examples.
