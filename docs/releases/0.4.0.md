# Note 0.4.0

## Split tab layouts

Note now supports optional left and right section columns inside a tab while preserving the original single-column layout as the default.

### Added

- `Layout = "Split"` and `Split = true` tab configuration
- `SplitGap` spacing configuration
- `StackAt` optional responsive stacking breakpoint
- `Side = "Left"` and `Side = "Right"` section placement
- `Tab:SetLayout(layout)`
- `Tab:GetLayout()`
- `Tab:SetSplitEnabled(enabled)`
- `Tab:SetStackBreakpoint(widthOrNil)`
- `Tab:IsStacked()`
- `Section:SetSide(side)`
- `Section:GetSide()`

### Behavior

- Tabs remain single-column unless split layout is explicitly enabled.
- Split tabs remain two-column at narrow widths by default.
- Setting `StackAt` enables optional one-column stacking below that content width.
- Left and right columns maintain independent vertical section stacks.
- Existing sections can move between sides without being recreated.
- Search, scrolling, section visibility, and collapsible section sizing continue to update the tab canvas.

See [`examples/split-layout.lua`](../../examples/split-layout.lua) and [`docs/split-layout.md`](../split-layout.md).
